Modifiers, three ways

Base: hold home-row letters. Menu: tap right home-row one-shots (5 s expiry), then choose a layer or Base. Utility layers: hold plain modifier keys. Ctrl+Alt alone: use the plain strip.

Spanish & Compose

AltGr + A/E/I/O/U → áéíóú; Y → ü; N → ñ; / → ¿; Shift+1 → ¡. Add Shift for capitals. Menu → C sends Compose and returns to Base.
